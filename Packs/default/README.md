# Pack padrão

Poses, clipes e stickers do Glyph. Licença: **CC BY 4.0** (`LICENSE-ASSETS`),
separada do código (Apache-2.0).

- `clips/` — clipes de animação em JSON (formato em `docs/ANIMATION.md`).
- `poses/` — poses nomeadas, reutilizáveis nos clipes.
- `stickers/` — ícones internos (memória, tarefa, ideia) como traços.
