# Decisões de arquitetura (ADR)

Uma decisão por arquivo, numerada, no formato: contexto, decisão,
consequências. Uma ADR aceita não é editada: é substituída por outra.

Obrigatório abrir ADR para: nova dependência, mudança incompatível no
protocolo, mudança na trava de irreversíveis ou na escada de confiança
(essas últimas só como proposta, para revisão humana).
